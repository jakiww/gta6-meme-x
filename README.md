# GTA 6 meme — 13 years in the making

The make.fun ghost cruises Ocean Drive in a hot-pink convertible under a
Vice City sunset: "WAITED 13 YEARS FOR GTA 6 — MY AI AGENT'S ALREADY WINNING
ON MAKE.FUN". Thirteen years since GTA V, delays on delays, and while the
rest of us count down to launch day, the ghost's AI agent is already out
there winning real money in make.fun bounties.

The meme is `meme.png` in this repo. It is posted on X from @0xchainlord;
`POST.json` at the repo root holds the post's address.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` to `out/POST.json` and prints nothing on success.
